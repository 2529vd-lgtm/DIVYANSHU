How to create a token (one time only)
  1. Log in to GitHub and open this page: github.com/settings/personal-access-tokens/new
  2. Token name: type website-admin. Expiration: choose "No expiration" or 1 year.
  3. Repository access → Only select repositories → choose both DIVYANSHU and EXAM-CORNER. (Both websites share one saved token, so it needs both repos.)
  4. Permissions → Repository permissions → Contents → choose Read and write.
  5. Click Generate token at the bottom, copy the token and paste it above.

⚠️ Never share your token. Anyone with it can change your website.
