Login

Upload karne ke liye apna GitHub token daalein. Ye token sirf aapke browser mein rehta hai.

Token kaise banayein? (sirf ek baar)
  1. GitHub par login karke ye page kholo: github.com/settings/personal-access-tokens/new
  2. Token name: website-admin likho. Expiration: "No expiration" ya 1 saal chuno.
  3. Repository access → Only select repositories → DIVYANSHU chuno.
  4. Permissions → Repository permissions → Contents → Read and write chuno.
  5. Neeche Generate token dabao, token copy karo aur upar paste karo.

⚠️ Token kisi ke saath share mat karna. Token se koi bhi aapki website badal sakta hai.
